Rongoe — nieuwe MacBook (korte stappen)
========================================
GitHub: https://github.com/joeryvdberg/rongoe  (branch: main)

1) Software
   - Node.js LTS: https://nodejs.org
   - Git: Terminal → xcode-select --install

2) Project binnenhalen (geen handmatig kopiëren van code nodig)
   mkdir -p ~/Projects
   cd ~/Projects
   git clone https://github.com/joeryvdberg/rongoe.git
   cd rongoe

3) Dependencies
   npm install

4) .env
   Voor dit project hoef je normaal GEEN .env te zetten om lokaal te starten:
   Supabase staat nu in src/App.jsx.
   (Wil je later overstappen op VITE_* variabelen: maak dan .env en haal de waarden
   uit Supabase Project Settings → API — zelfde idee als Lyyve.)

5) Starten
   npm run dev
   Open de URL die Vite toont (meestal http://localhost:5173 )

6) Optioneel
   npm run build
   npm run lint

Deploy
   GitHub Actions deployt naar Pages na push naar main; check repo Settings → Pages.

7) Supabase — tabel voor “aanwezig bevestigen” (eerstvolgende wedstrijd)
   In Supabase → SQL Editor, voer uit:

   create table if not exists public.match_presence (
     match_date text not null,
     player_id bigint not null references public.players(id) on delete cascade,
     confirmed_at timestamptz not null default now(),
     primary key (match_date, player_id)
   );

   alter table public.match_presence enable row level security;

   create policy "match_presence_anon_all"
     on public.match_presence for all
     using (true) with check (true);

   (Zelfde idee als je andere tabellen: anon key uit de app mag lezen/schrijven.)
